The example

A projector shows sinusoidal fringes at 0°, 120° and 240°; an offset camera records three frames for phase and height calibration.

  1. Match each camera frame to its phase step.
  2. Locate the need for a reference plane and phase unwrapping.

Follow the arrangement

  1. Fringe projector (DMD) — Example 16 projector pixels per fringe period.
  2. Projection lens (Thin convex lens) — Image fringes onto the object.
  3. Surface under test (Sample) — Height distorts observed fringe phase.
  4. Offset camera (Camera) — View the surface from a distinct angle.
  5. Three-frame phase — Estimate wrapped phase using the three exposures.
  6. Phase sequencer — Synchronize pattern and camera exposure.
  7. Reference plane — Measure the baseline phase before the object.
