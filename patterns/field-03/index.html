FIELD-03 · Pattern family

Counterpropagating-loop interferometry

Compare opposite propagation directions around one optical loop.

Schematic exampleTriangular Sagnac loop

633 nm input — One coherent input.

Diagram scope: Loop area and rotation sensitivity are not computed; schematic arrows do not represent a gyro or phase-calibrated Sagnac interferometer. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

A 50/50 splitter launches clockwise and counterclockwise beams around the same three-mirror loop before recombination.

  1. Trace both directions around the same loop.
  2. Distinguish reciprocal shared-path changes from nonreciprocal effects or rotation.

Follow the arrangement

  1. 633 nm input (CW Laser) — One coherent input.
  2. Loop splitter (Beamsplitter) — Launches two counterpropagating copies.
  3. Upper loop mirror (Mirror) — Shared loop segment.
  4. Far loop mirror (Mirror) — Closes the triangular area.
  5. Lower loop mirror (Mirror) — Both directions encounter this mirror.
  6. Loop output (Camera) — Recombined counterpropagating fields.

Design choices

Arrangement and variants

Sagnac loop with a splitter and controlled polarization or phase.

Key constraints

Nonreciprocal effects, polarization drift, and imbalance affect the observable signal.
