The example

A preparation interferometer separates early and late bins by 2 ns; a matched analyzer recombines alternatives in the central detection time slot.

  1. Enumerate short–short, short–long, long–short and long–long histories.
  2. Explain why only the two middle histories can interfere.

Follow the arrangement

  1. Single photon — Input photon before preparation.
  2. Preparation split (Beamsplitter) — Create short and long alternatives.
  3. 2 ns delay (Mechanical delay line) — Long preparation arm.
  4. Preparation join (Beamsplitter) — Emit an early/late superposition.
  5. Matched analyzer — Second interferometer with the same imbalance.
  6. Short arm — Preparation reference path.
  7. Central-slot gate — Select alternatives with equal total travel time.
