The example

A reference phase steps through 0, π/2, π and 3π/2 while the object stays fixed; four recorded intensities specify a wrapped phase estimate.

Follow the arrangement

  1. 633 nm source (CW Laser) — Common coherent source.
  2. Two-arm split (Beamsplitter) — Divide object and reference illumination.
  3. Object arm (Sample) — Keep the specimen unchanged during all four frames.
  4. Recombiner (Beamsplitter) — Combine phase-stepped reference and object.
  5. Four-frame camera (Camera) — Capture one frame per phase state.
  6. Reference phase (Phase modulator) — Set 0, π/2, π and 3π/2.
  7. Phase sequencer — Use atan2(I3−I1,I0−I2) with stated indexing.

Design choices

Arrangement and variants

Interferometer with controlled phase shifts and multiple intensity measurements.

Key constraints

Motion between frames and inaccurate phase steps bias the reconstruction.
