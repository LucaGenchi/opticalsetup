SENSE-01 · Optical layout

Coaxial transmit/receive

Share an external aperture while separating internal outgoing and return channels.

The example

A polarized 905 nm transmit pulse uses a quarter-wave plate and common telescope; the returning polarization is routed to a receiver.

Follow the arrangement

  1. 905 nm pulse (Pulsed Laser) — Outgoing ranging light.
  2. Send / return PBS (Polarizing BS) — Transmit one linear polarization and receive the orthogonal one.
  3. Quarter-wave plate (λ/4 waveplate) — Double traversal changes the return polarization for a suitable reflector.
  4. Common telescope (Conjugated thin lens pair) — One shared entrance aperture.
  5. Reflective target — Example target at 20 m.
  6. Return receiver (Photodetector) — Separate detector port.

Design choices

Arrangement and variants

Shared telescope or objective with spectral, polarization, or nonreciprocal separation.

Key constraints

Transmit leakage, back-reflections, and near-field overlap limit weak-return detection.
