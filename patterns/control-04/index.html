CONTROL-04 · Control architecture

Round-trip phase stabilization

Use a returned reference to compensate optical-link phase fluctuations.

Schematic exampleRound-trip compensated fiber frequency link

1550 nm reference — Stable local carrier.

Diagram scope: Delay-limited rejection, nonreciprocity and phase slips are not simulated; a round-trip measurement is not direct proof of one-way stability. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

A local AOM shifts a 1550 nm carrier before a 1 km fiber; a remote reflector returns light for phase comparison and a servo precompensates the link.

  1. Count the AOM traversals when assigning the beat frequency.
  2. Identify the independent remote comparison needed to verify one-way transfer.

Follow the arrangement

  1. 1550 nm reference (CW Laser) — Stable local carrier.
  2. Link AOM (AOM) — Example 80 MHz shift and phase correction.
  3. 1 km fiber — Environmental path fluctuations affect both traversals.
  4. Remote reflector (Retroreflector) — Return a sampled field while delivering remote light.
  5. Remote user — Receive the one-way compensated field.
  6. Local beat (Photodetector) — Compare returning field with a local reference.
  7. Phase servo — Apply correction inferred from the round trip.

Design choices

Arrangement and variants

Round-trip reference path, phase comparison, and compensating actuator.

Key constraints

Propagation delay limits control bandwidth; nonreciprocal disturbances may remain.
