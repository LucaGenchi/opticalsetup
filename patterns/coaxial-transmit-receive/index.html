SENSE-01 · Optical layout · Setup available

Coaxial transmit/receive

Share an external aperture while separating internal outgoing and return channels.

Open setup in canvas ↗Download setup

Model limits. This native common-aperture geometry computes ideal polarization routing and a specular mirror return. Diffuse-target depolarization, telescope throughput, lidar range estimation and receiver electronics are not modeled.

The setup

A 905 nm beam crosses a PBS, a quarter-wave plate and one shared lens before reflecting from a specular target. Its double-pass polarization directs the return into a separate detector.

  1. Inspect the return detector with the quarter-wave axis at 45°; it receives the orthogonal linear return polarization.
  2. Set the quarter-wave axis to 0° to suppress the receive port, or rotate the target mirror away to remove the returned path.

Components in this setup

  • CW Laser
  • Polarizing BS
  • λ/4 waveplate
  • Thin convex lens
  • Mirror
  • Photodetector

Arrangement and variants

Shared telescope or objective with spectral, polarization, or nonreciprocal separation.

Design constraints

Transmit leakage, back-reflections, and near-field overlap limit weak-return detection.
