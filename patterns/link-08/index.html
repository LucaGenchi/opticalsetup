LINK-08 · Optical layout

Optical phased-array steering

Control emitter phases to steer a combined far-field distribution.

Schematic exampleFour-emitter phase-gradient steering

1550 nm carrier — Coherent source shared by all emitters.

Diagram scope: Far-field diffraction, grating lobes and element radiation patterns are not evaluated. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

Four equal-amplitude emitters at spacing λ/2 receive phases 0, π/4, π/2 and 3π/4; their far-field contributions are intended to steer together.

  1. Reverse the phase ramp to reverse the intended steering sign.
  2. Distinguish emitter pitch from the drawn diagram spacing.

Follow the arrangement

  1. 1550 nm carrier (CW Laser) — Coherent source shared by all emitters.
  2. Four-way feed — Equal nominal amplitudes.
  3. Emitter 0 / 1 — First pair phases 0 and π/4.
  4. Emitter 2 / 3 — Second pair phases π/2 and 3π/4.
  5. Far-field lobe — For this phase convention sinθ=−1/4.
  6. Phase controller — Set a uniform phase increment across the aperture.
