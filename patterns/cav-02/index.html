The example

A 1064 nm seed enters a bow-tie cavity with two curved mirrors focusing through a nonlinear crystal. Reflection provides a locking channel; transmission monitors buildup.

  1. Follow the closed round trip and distinguish it from a nonresonant multipass path.
  2. Identify input-coupler loss matching and phase locking as separate requirements for buildup.

Follow the arrangement

  1. 1064 nm seed (CW Laser) — Input phase and mode must match the resonant cavity.
  2. Input coupler (Mirror) — Its transmission is chosen against round-trip loss.
  3. Curved mirror 1 (Concave mirror) — Forms one side of the crystal focus.
  4. Intracavity focus (Crystal) — A chosen nonlinear interaction uses circulating power.
  5. Curved mirror 2 (Concave mirror) — Closes the focusing leg.
  6. Return fold (Mirror) — Returns the beam to the input coupler.
  7. Reflection lock sensor (Photodetector) — Error signal must maintain resonance.
  8. Converted output — Extracted wavelength is separated from the fundamental.

Design choices

Arrangement and variants

Mode-matched source, input coupler, resonator, and resonance control.

Key constraints

Coupling must account for internal losses; detuning and mode mismatch reduce buildup.
