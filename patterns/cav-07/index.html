The example

A circulating pulse builds in a cavity with weak normal outcoupling. A timed polarization switch routes one stored pulse into a high-transmission output port.

  1. Follow the storage loop and the mutually selected dump route.
  2. Compare extraction of existing light with Q-switch release of stored inversion.

Follow the arrangement

  1. Seed / gain section — Establishes circulating optical energy.
  2. Storage mirror A (Mirror) — One corner of the storage loop.
  3. Dump Pockels cell (EOM) — A short voltage gate changes pulse polarization.
  4. Dump polarizer (Polarizing BS) — Routes the switched pulse out of the loop.
  5. Storage mirror B (Mirror) — Returns unswitched pulses to the storage section.
  6. Storage mirror C (Mirror) — Completes the circulating path.
  7. Dumped pulse — Extracts stored light in a chosen circulation.
