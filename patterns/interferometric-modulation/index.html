Interferometric modulation

Convert a controlled phase change into amplitude modulation through recombination.

Open setup in canvas ↗Download setup

Model limits. The workbench computes supported monochromatic camera interference and static phase drive. This free-space equivalent has no waveguides, electrodes, symbol stream, RF bandwidth, modulator chirp or bias-control servo.

The setup

A sized 532 nm beam divides into equal-length arms. A native phase modulator writes a held phase into one arm; complementary camera ports measure the resulting interference.

  1. Compare port A and port B at 0° phase drive, then set the phase modulator depth to 180° and compare the ports again.
  2. Set 90° for the intermediate state; distinguish phase-driven interference from absorption in either arm.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Phase modulator
  • Mirror
  • Camera

Arrangement and variants

Mach-Zehnder modulator with one or both arms phase-driven.

Design constraints

Bias drift, chirp, extinction, optical loss, and electrical bandwidth matter.
