SENSE-03 · Measurement architecture

FMCW ranging

Compare a swept optical signal with its delayed return to infer distance and motion.

Schematic exampleTriangular-chirp coherent ranging

Chirped source — Nominal chirp slope 10¹² Hz/s.

The example

A 1550 nm source sweeps 1 GHz in 1 ms; an LO branch mixes with the target return to separate range and Doppler on opposite chirp slopes.

  1. Compare range beat sign on up and down chirps.
  2. Identify the source coherence requirement over a round trip.

Follow the arrangement

  1. Chirped source (CW Laser) — Nominal chirp slope 10¹² Hz/s.
  2. LO tap (Beamsplitter) — Split local reference from transmit power.
  3. 20 m target — Outgoing and return propagation delay.
  4. Coherent mixer (Beamsplitter) — Overlap return with local oscillator.
  5. Balanced receiver (Photodetector) — Measure beat frequency on both slopes.
  6. Local oscillator — Reference path bypasses the target.
  7. Beat estimator — Use up/down frequencies to separate delay and velocity.

Design choices

Arrangement and variants

Frequency-swept source, local reference, return mixer, and beat analysis.

Key constraints

Sweep linearity, coherence, Doppler coupling, and ambiguity require calibration.
