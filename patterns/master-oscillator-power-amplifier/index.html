Patterns / Recirculating and amplifying light

CAV-04 · Optical layout · Setup available

Master oscillator-power amplifier

Separate beam generation and spectral control from power amplification.

Open setup in canvas ↗Download setup

Model limits. This is a parametric MOPA implementation rather than an inversion amplifier. It models pump-limited seeded gain, not gain-medium storage, ASE, phase matching or amplifier isolation.

The setup

A native 800 nm master pulse source seeds the OPA lower port; a separate 532 nm pump supplies amplification energy. The signal, residual pump and idler leave distinct physical output ports.

  1. Inspect the seed and pump port heights and the separately dumped residual pump and idler.
  2. Set pump average power to zero and compare amplified seed output with the unpumped seed.

Components in this setup

  • Pulsed Laser
  • Mirror
  • OPA
  • Beam dump
  • Photodetector

Arrangement and variants

Controlled seed source followed by one or more amplifier stages.

Design constraints

Amplified noise, feedback, nonlinear effects, and thermal distortion constrain scaling.
