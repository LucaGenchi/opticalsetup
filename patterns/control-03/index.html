CONTROL-03 · Pattern family

Frequency locking to a reference

Derive an error signal from a reference and control source frequency.

Schematic examplePound–Drever–Hall cavity frequency lock

1064 nm laser — Frequency actuator receives the controller output.

The example

A 1064 nm source receives 20 MHz phase sidebands; reflected reference-cavity light is demodulated into an error signal that drives laser frequency.

  1. Follow the reflected field instead of mistaking transmitted power for the PDH error.
  2. Describe why modulation frequency must be chosen relative to cavity linewidth and free spectral range.

Follow the arrangement

  1. 1064 nm laser (CW Laser) — Frequency actuator receives the controller output.
  2. 20 MHz sidebands (EOM) — Phase modulation produces sensing sidebands.
  3. Reflection separator (Beamsplitter) — Route cavity reflection toward detection.
  4. Reference cavity — Example 100 mm resonator sets the frequency reference.
  5. Fast photodiode (Photodetector) — Detect carrier/sideband beating in reflection.
  6. RF reference — Coherent 20 MHz demodulation reference.
  7. Mixer and servo — Filter the signed error and apply feedback.

Design choices

Arrangement and variants

Reference cavity or transition, discriminating readout, and frequency actuator; PDH is one variant.

Key constraints

Reference drift, discriminator slope, residual modulation, and control bandwidth limit stability.

References
