COMPUTE-02 · Measurement architecture · Setup available

Phase-shifting interferometry

Acquire known reference-phase steps to recover optical phase.

Open setup in canvas ↗Download setup

Model limits. The native camera computes supported monochromatic interference; this bench has manual phase acquisition. Frame sequencing, numerical phase extraction, unwrapping and specimen-motion rejection are not implemented.

The setup

A native 532 nm Mach–Zehnder records complementary camera intensity profiles while one arm’s phase modulator is manually set to 0°, 90°, 180° and 270°.

  1. Set the phase modulator depth to each of 0°, 90°, 180° and 270° and inspect both camera profiles.
  2. Disable camera interference to see why simple ray-power addition cannot supply phase-shifting data.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Phase modulator
  • Mirror
  • Camera

Arrangement and variants

Interferometer with controlled phase shifts and multiple intensity measurements.

Design constraints

Motion between frames and inaccurate phase steps bias the reconstruction.
