Low-coherence interferometry

Resolve optical path differences using broadband interference.

The example

A nominal 840 nm, 50 nm-bandwidth source feeds sample and reference arms; a spectrometer records their interferogram for depth reconstruction.

  1. Separate optical depth from physical layer thickness.
  2. Compare bandwidth-limited axial resolution with spectrometer sampling limits and dispersion mismatch.

Follow the arrangement

  1. 840 nm / 50 nm source — Broad bandwidth limits coherence length.
  2. Fiber coupler (Beamsplitter) — Splits into sample and reference arms.
  3. Layered specimen (Sample) — Reflections carry different optical path lengths.
  4. Reference mirror (Mirror) — Adjust delay and match dispersion.
  5. Interferogram spectrum (Diffraction grating) — Sample uniformly in wavenumber for reconstruction.
  6. Depth profile — Fourier reconstruction needs refractive-index interpretation.

Design choices

Arrangement and variants

Reference and sample arms with delay-scanned or spectrally resolved readout.

Key constraints

Bandwidth, dispersion matching, sampling, and refractive index determine depth interpretation.
