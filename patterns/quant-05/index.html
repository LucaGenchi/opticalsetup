QUANT-05 · Optical layout

Squeezed-field injection and readout

Deliver a squeezed field with the quadrature alignment needed for a measurement.

The example

A below-threshold parametric cavity supplies a squeezed field; a bright local oscillator sets the quadrature measured by a balanced receiver.

  1. Change the proposed LO phase from 0 to π/2 to select orthogonal quadratures.
  2. Identify the separate shot-noise measurement needed before claiming squeezing.

Follow the arrangement

  1. 532 nm pump (CW Laser) — Pump the nonlinear cavity below oscillation threshold.
  2. 1064 nm squeezer (OPO) — Supply the proposed squeezed-vacuum input.
  3. Homodyne splitter (Beamsplitter) — Combine squeezed input and local oscillator.
  4. Detector + (Photodetector) — First photodiode.
  5. Difference current — Subtract matched detector currents.
  6. 1064 nm LO (CW Laser) — Coherent phase reference, example 5 mW.
  7. Detector − (Photodetector) — Second photodiode.

Design choices

Arrangement and variants

Squeezed source, mode matching, phase control, and quadrature-sensitive readout.

Key constraints

Loss and phase errors degrade squeezing; useful quadrature can depend on frequency.
