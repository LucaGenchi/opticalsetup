LINK-02 · Optical layout

Interferometric modulation

Convert a controlled phase change into amplitude modulation through recombination.

Schematic examplePush-pull Mach–Zehnder transmitter

1550 nm carrier — Continuous input carrier.

The example

A 1550 nm carrier divides equally between two arms with opposite phase drives, then recombines at an intensity output.

  1. Trace both arms rather than treating the phase drive as absorption.
  2. Compare equal phase changes in both arms with opposite phase changes.

Follow the arrangement

  1. 1550 nm carrier (CW Laser) — Continuous input carrier.
  2. 50:50 coupler (Beamsplitter) — Divide field amplitude between arms.
  3. Positive phase (Phase modulator) — Upper arm drive +π/4 around quadrature.
  4. Output coupler (Beamsplitter) — Combine arm fields.
  5. Intensity output (Photodetector) — Read the modulated port.
  6. Negative phase (Phase modulator) — Lower arm drive −π/4.

Design choices

Arrangement and variants

Mach-Zehnder modulator with one or both arms phase-driven.

Key constraints

Bias drift, chirp, extinction, optical loss, and electrical bandwidth matter.
