Patterns / Scanning and changing optical paths

SCAN-05 · Pattern family · Setup available

Remote focusing

Shift the observed or excited plane by adjusting remote optics.

Open setup in canvas ↗Download setup

Model limits. The native generic objectives demonstrate geometric remote focus. Refractive-index pupil matching, high-NA aberration cancellation and calibrated axial magnification are not modeled.

The setup

A real objective focuses onto a remote end mirror; its return is split downward into a stationary second objective and camera. The end mirror can be translated independently.

  1. Trace both passes through the remote objective.
  2. Translate the remote mirror and inspect the changed return focus at the fixed camera.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Objective
  • Mirror
  • Camera

Arrangement and variants

Matched remote objectives, moving remote reflector, or tunable focusing optics.

Design constraints

Pupil matching and refractive-index conditions control scan-induced aberrations.

References

  1. Botcherby et al.: aberration-free optical refocusing
