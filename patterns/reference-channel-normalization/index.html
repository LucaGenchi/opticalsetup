Patterns / Stabilizing, calibrating, and diagnosing

CONTROL-06 · Measurement architecture · Setup available

Reference-channel normalization

Compare measurement and reference signals to separate source changes from sample response.

Open setup in canvas ↗Download setup

Model limits. The native optical branches and absolute powers from the configured source are traced. Ratio computation is manual; detector noise, dark subtraction, electronics gain, drift and uncertainty propagation are not simulated.

The setup

A 50:50 splitter sends one branch through a 60%-transmitting sample and the other to a reference detector. Native power meters report both channels for manual normalization.

  1. Compare sample and reference powers; their ratio is 0.6 with matched source fractions and this sample setting.
  2. Double source power to verify both powers scale together; set sample transmission to zero to check the opaque boundary.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Sample
  • Power meter

Arrangement and variants

Simultaneous or interleaved reference readout and calibrated normalization.

Design constraints

Different detector responses and path drifts are not removed automatically.
