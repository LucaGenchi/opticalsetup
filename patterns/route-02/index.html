Polarization combining and splitting

Use orthogonal polarization states as separable optical channels.

Ray exampleEqual-power polarization splitter

45° linear input — Equal components in the PBS basis.

Ray model: Ideal Stokes projection is traced; finite PBS extinction, coating phase and depolarization are absent.

The example

A 532 nm beam with linear polarization at 45° enters a PBS and divides into orthogonal polarization channels.

  1. Compare detector powers and polarization states in the traced example.
  2. Set input polarization to 0° or 90° and verify extinction of the complementary port.

Follow the arrangement

  1. 45° linear input (CW Laser) — Equal components in the PBS basis.
  2. Polarizing splitter (Polarizing BS) — Projects the input onto two orthogonal linear states.
  3. Transmitted channel (Photodetector) — One linear basis state.
  4. Reflected channel (Photodetector) — Orthogonal linear basis state.

Design choices

Arrangement and variants

Polarizing beamsplitter with polarization preparation or recovery optics.

Key constraints

Finite extinction and downstream birefringence mix the channels.
