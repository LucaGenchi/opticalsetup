Cross-dispersed spectroscopy

Separate overlapping spectral orders using an additional dispersion direction.

The example

An illustrative 31.6 lines/mm echelle at high incidence disperses several orders; a prism supplies orthogonal dispersion before a 2D camera.

  1. Follow high dispersion along one detector axis and order separation along the other.
  2. Compare adjacent-order spacing with slit image height before claiming usable coverage.

Follow the arrangement

  1. Entrance slit (Slit) — A narrow spatial input prevents order overlap.
  2. Collimator (Thin convex lens) — Presents the same incidence angle across the pupil.
  3. 31.6 lines/mm echelle (Diffraction grating) — High diffraction orders provide fine dispersion.
  4. Cross-dispersing prism (Prism) — Separates orders in the second detector axis.
  5. 2D order map (Camera) — Each stripe contains a different wavelength interval.
  6. Overlapping orders — Without the cross disperser different orders would coincide.

Design choices

Arrangement and variants

High-dispersion element followed by an orthogonal cross-disperser and camera.

Key constraints

Order separation, detector area, and calibration limit spectral coverage.
