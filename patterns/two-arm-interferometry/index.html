FIELD-01 · Pattern family · Setup available

Two-arm interferometry

Compare phase or path changes between distinct optical arms.

Open setup in canvas ↗Download setup

Model limits. Native ray paths and camera coherent-field readout are computed within the existing scalar/coherence model. No RF electronics, noise, real coating phase, wavefront aberrations or calibrated interferometer sensitivity are inferred.

The setup

A real two-splitter Mach–Zehnder uses two folded 200 mm arms and a native phase plate. Two camera ports inspect the coherent recombination.

  1. Compare the complementary port profiles.
  2. Set the phase-plate optical path to 0.266 µm at 532 nm and inspect the changed interference.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Mirror
  • Phase object
  • Camera

Arrangement and variants

Michelson or Mach-Zehnder split, propagate, and recombine arrangements.

Design constraints

Coherence, mode overlap, differential drift, and polarization set interference visibility.
