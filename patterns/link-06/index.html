Adiabatic mode conversion

Transfer light between modal geometries using gradual structural changes.

Schematic exampleWide-to-narrow guided mode transition

1550 nm input — Common test illumination.

The example

A 3 µm entrance guide tapers over a proposed 500 µm length into a 450 nm silicon wire; a monitor compares direct and tapered paths.

  1. Locate the transition rather than assigning focusing to a ray lens.
  2. Compare taper length and local mode separation qualitatively.

Follow the arrangement

  1. 1550 nm input (CW Laser) — Common test illumination.
  2. Test split (Beamsplitter) — Feed taper and reference routes.
  3. 500 µm taper — Gradually change guide cross section.
  4. 450 nm wire — Receive the compressed guided mode.
  5. Taper monitor (Photodetector) — Compare transmitted guided power.
  6. Untapered reference — A reference route isolates coupling and source drift.
  7. Reference monitor (Photodetector) — Read reference transmission.

Arrangement and variants
