Integrating-sphere measurement

Collect light across directions for radiometric characterization.

The example

A baffled source port illuminates a diffuse sphere wall; a detector sees the multiply scattered field, with a calibrated reference source substituted for the test lamp.

  1. Inspect the baffle role before interpreting a detector reading as total flux.
  2. Explain why installing a different lamp changes sphere absorption.

Follow the arrangement

  1. Test lamp (Point source) — Unknown total optical flux.
  2. Input port — Inject into the sphere without direct detector illumination.
  3. Diffuse sphere wall (Diffuser) — Multiple reflections mix directions.
  4. Detector baffle (Invisible blocker) — Block direct source-to-detector sightline.
  5. Sphere detector (Photodetector) — Sample wall radiance through a separate port.
  6. Calibrated standard (Point source) — Substitute at the same input geometry.
  7. Flux comparison — Use standard response and self-absorption correction.
  8. Second wall patch (Diffuser) — A distinct diffuse surface receives redistributed light.
