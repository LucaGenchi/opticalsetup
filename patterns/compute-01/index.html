COMPUTE-01 · Measurement architecture

Off-axis holography

Encode a field with an angled reference so its information can be separated computationally.

Follow the arrangement

  1. 633 nm source (CW Laser) — Coherent common illumination.
  2. Arm splitter (Beamsplitter) — Supply object and reference paths.
  3. Transparent object (Sample) — Object introduces phase and amplitude structure.
  4. Tilted recombination (Beamsplitter) — Introduce a small reference-angle offset.
  5. Hologram camera (Camera) — Record off-axis intensity fringes.
  6. Tilt reference (Mirror) — Example 2° relative angle at the camera.
  7. Sideband filter — Select one Fourier carrier sideband, then invert.

Design choices

Arrangement and variants

Coherent object/reference combination at a controlled angle on a spatial detector.

Key constraints

Reference coherence, spatial sampling, and order separation limit recoverable bandwidth.
