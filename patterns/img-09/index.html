IMG-09 · Pattern family

Compensated zoom

Change magnification while maintaining a designated image plane.

Schematic exampleTwo-group compensated zoom

Fixed object — Keep the object position fixed throughout zoom.

Diagram scope: No prescription or cam law is solved here; arbitrary group translations do not constitute a working compensated zoom. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

A movable variator changes nominal magnification from 1× to 2× while a separate compensator keeps the final image plane fixed.

  1. Identify the two independent moving groups.
  2. Compare a 1× and 2× endpoint only after checking that both share the fixed sensor plane.

Follow the arrangement

  1. Fixed object — Keep the object position fixed throughout zoom.
  2. Fixed front group (Thin convex lens) — Collects the object field.
  3. Variator (Thin convex lens) — Moves to change the system focal length.
  4. Compensator (Thin convex lens) — Moves on a different trajectory to restore focus.
  5. Fixed image plane (Camera) — Sensor position is not the compensating actuator.
  6. Coupled motion law — Two trajectories must be solved together.

Design choices

Arrangement and variants

Coordinated variator and compensator groups; mechanical or optical compensation.

Key constraints

Focus, pupil location, and aberrations must remain controlled throughout the zoom range.
