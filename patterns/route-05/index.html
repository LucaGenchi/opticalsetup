ROUTE-05 · Pattern family

Nonreciprocal routing

Direct light differently in forward and reverse propagation.

Schematic exampleFaraday isolator for laser protection

Laser output — Protect against light returning from downstream optics.

The example

A 45° Faraday rotator between 0° and 45° polarizers transmits forward light while the nonreciprocal return reaches the first polarizer at 90°.

  1. Compare same-sense Faraday rotation in both propagation directions.
  2. Identify where reverse power is absorbed or dumped.

Follow the arrangement

  1. Laser output (CW Laser) — Protect against light returning from downstream optics.
  2. 0° input polarizer (Polarizer) — Defines the forward input state.
  3. 45° Faraday rotation (Optical isolator) — Rotation adds on the reverse pass rather than undoing itself.
  4. 45° output polarizer (Polarizer) — Aligned to the forward state.
  5. Reflective load — May send a reverse beam.
  6. Return rejection (Beam dump) — Reverse state is crossed at the input polarizer.

Design choices

Arrangement and variants

Faraday rotation with polarizers or multiport polarization-routing stages.

Key constraints

Isolation, insertion loss, bandwidth, and power handling constrain operation.
