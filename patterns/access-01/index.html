Serial image relay

Transfer an image through a long narrow optical channel.

The example

Three illustrative 1:1 relay stages transport an image through a rigid probe. Intermediate image planes separate the stages; peripheral illumination is supplied independently.

  1. Identify each intermediate image instead of treating the tube as one lens.
  2. Track inversion through successive relay stages and check clear apertures against field size.

Follow the arrangement

  1. Distal specimen (Sample) — Defines the object plane outside the probe.
  2. Distal objective (Objective) — Forms the first internal image.
  3. Relay stage 1 / image I₁ (Lens group) — First nominal unity relay preserves the field orientation rule.
  4. Relay stage 2 / image I₂ (Lens group) — Second intermediate image is conjugate to I₁.
  5. Relay 3 / proximal camera (Camera) — Last relay presents the transmitted image to the camera.
  6. Peripheral illumination — A separate light channel illuminates the specimen without using the image relay.

Design choices

Arrangement and variants

Repeated relay stages using rod lenses, conventional lenses, or GRIN elements.

Key constraints

Diameter, field, numerical aperture, accumulated aberrations, and assembly tolerances compete.
