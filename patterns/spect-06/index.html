SPECT-06 · Measurement architecture

Fourier-transform spectroscopy

Recover spectral content from an interferogram measured versus optical delay.

Schematic exampleScanning Michelson Fourier-transform spectrometer

Broadband input — Finite coherence determines the useful scan envelope.

The example

A broadband input divides into a fixed arm and a moving retroreflector arm. Record intensity versus optical-path difference; transform the interferogram only after sampling and reference calibration.

  1. Distinguish mirror displacement from round-trip optical-path difference.
  2. Compare long scan range with fine OPD sampling; they set different spectral constraints.

Follow the arrangement

  1. Broadband input (Supercontinuum laser) — Finite coherence determines the useful scan envelope.
  2. 50:50 splitter (Beamsplitter) — Launches and recombines both arms.
  3. Fixed retroreflector (Retroreflector) — Defines the reference optical-path length.
  4. Scanning retroreflector (Retroreflector) — A displacement Δx changes round-trip path by 2Δx.
  5. Interferogram detector (Photodetector) — Records interference as delay is scanned.
  6. Sample / Fourier transform — Turns calibrated path samples into a spectrum.
