ROUTE-04 · Optical layout

Polarization-based send/return separation

Distinguish outgoing and returning light by their polarization transformations.

The example

A PBS transmits horizontal input through a quarter-wave plate at 45°; reflection and the second pass produce a vertical return at the other port.

  1. Count two passes through the quarter-wave plate.
  2. Compare a specular reflector with a depolarizing sample that leaks into both ports.

Follow the arrangement

  1. Horizontal laser (CW Laser) — Linear polarization passes the send port.
  2. Send/return PBS (Polarizing BS) — Separate return by orthogonal polarization.
  3. QWP · 45° (λ/4 waveplate) — First pass converts linear to circular; second pass rotates linear state.
  4. Reflecting target (Mirror) — Return must preserve the required polarization transformation.
  5. Return detector (Photodetector) — Collects the orthogonal PBS port.

Design choices

Arrangement and variants

Polarizing beamsplitter, quarter-wave plate, and reflective return path.

Key constraints

Sample depolarization and imperfect retardance cause leakage between ports.
