Heralded photon generation

Use detection in one output of a pair source to announce a correlated photon.

Native nonlinear conversion is classical. There is no photon-pair probability model, herald counter or coincidence gate, so an idler detector cannot herald a single photon in the workbench.

There is no entangled pair source, quantum polarization state or coincidence analyzer. A native Sagnac layout alone cannot represent the essential entangled-pair preparation and analysis.

Two-photon interference

Native beamsplitters and cameras compute supported classical interference, but no single-photon counters or two-photon coincidence/Hong–Ou–Mandel interaction exist.
