Operating in X-ray and EUV regimes

8 optical patterns for operating in x-ray and euv regimes: compare arrangements, applications and design constraints, with 0 OpticalSetup setups to explore.

XRAY-01 · Optical layout · No setup available

Orthogonal grazing-incidence focusing

Focus the two transverse axes using separate crossed grazing-incidence mirrors.

Source wavelengths start at 150 nm, and the registry has no energy-dependent X-ray grazing-incidence mirrors or two orthogonal transverse focusing planes.

XRAY-02 · Pattern family · No setup available

Nested grazing-incidence imaging

Collect and image short-wavelength radiation using nested reflecting surface pairs.

There are no X-ray wavelengths or nested axisymmetric Wolter shell pairs; a visible 2D conic mirror does not implement this collecting geometry.

XRAY-03 · Pattern family · No setup available

Wide-field micropore imaging

Use many small reflecting channels to form images across a broad field.

Square micropore arrays, orthogonal wall-graze paths and wide-field lobster-eye geometry are absent, as are X-ray source wavelengths.

XRAY-04 · Pattern family · No setup available

Distributed refractive power

Accumulate useful focusing power from a sequence of weak refractive elements.

There are no X-ray wavelengths, refractive-decrement materials or selectable compound X-ray lens cartridges; visible glass lenses cannot substitute.

XRAY-05 · Optical layout · No setup available

Diffractive focusing with order selection

Isolate useful focused diffraction orders from unwanted transmitted and diffracted light.

There is no X-ray zone plate with diffraction orders and a central stop; the scalar metalens proxy does not implement zone-plate order sorting.

XRAY-06 · Measurement architecture · No setup available

Propagation-based phase contrast

Convert sample-induced phase structure into intensity through propagation.

X-ray wavelengths and free-space Fresnel field propagation are absent; ray propagation cannot create the required phase-to-intensity fringes.

XRAY-07 · Pattern family · No setup available

Grating-based phase analysis

Encode phase gradients and small-angle scattering into measurable fringe changes.

Source, phase and analyzer X-ray grating functions with Talbot interference and phase-stepped visibility readout are absent.

XRAY-08 · Pattern family · No setup available

Multilayer reflective transport

Guide and image strongly absorbed wavelengths using band-selective reflective surfaces.

The 13.5 nm wavelength is outside source bounds and no multilayer EUV coating or reflective-mask projection prescription exists.
