SPECT-07 · Optical layout · Setup available

Excitation cleanup and rejection

Suppress source impurities and source leakage around a weak collected signal.

Open setup in canvas ↗Download setup

Model limits. Raman channel yield and angular emission are simplified specimen inputs. Real filter optical density, molecular Raman tensors, linewidths and calibrated signal strength are not inferred.

The setup

A native 488 nm bandpass cleans the pump before a Raman specimen. The return collection branch includes a long-pass filter that rejects excitation before the photodetector.

  1. Inspect the specimen Raman material fingerprint and verify that its return wavelengths clear the long-pass cutoff.
  2. Raise the long-pass cutoff beyond the Raman line and compare detected signal.

Components in this setup

  • CW Laser
  • Filter
  • Dichroic mirror
  • Thin convex lens
  • Sample
  • Slit
  • Photodetector

Arrangement and variants

Excitation cleanup filter followed by collection-side notch, edge, or band filters.

Design constraints

Filter edge placement, incidence angle, and residual fluorescence set usable sensitivity.
