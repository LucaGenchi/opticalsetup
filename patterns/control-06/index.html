CONTROL-06 · Measurement architecture

Reference-channel normalization

Compare measurement and reference signals to separate source changes from sample response.

Schematic exampleDual-channel transmission normalization

532 nm source — Common intensity fluctuations enter both channels.

The example

A 50:50 split feeds a sample photodiode and a bypass reference; the corrected sample/reference ratio is compared with an empty-sample baseline.

  1. Double the proposed source power and compare numerator and denominator changes.
  2. Identify the zero-reference case where division must be rejected.

Follow the arrangement

  1. 532 nm source (CW Laser) — Common intensity fluctuations enter both channels.
  2. Sample/reference split (Beamsplitter) — Nominal equal incident fractions.
  3. Absorbing sample (Sample) — Example target transmission 0.6.
  4. Sample diode (Photodetector) — Record transmitted signal S.
  5. Corrected S/R — Subtract dark offsets before division, then divide by baseline ratio.
  6. Reference diode (Photodetector) — Record bypass reference R.
  7. Empty-cell baseline — Measure channel throughput and detector gain ratio.

Design choices

Arrangement and variants

Simultaneous or interleaved reference readout and calibrated normalization.

Key constraints

Different detector responses and path drifts are not removed automatically.
