SPECT-05 · Pattern family · Setup available

Cascaded spectral filtering

Use successive selection stages to improve out-of-band rejection.

Open setup in canvas ↗Download setup

Model limits. The supplied ray scene uses idealized bandpass and split models. It does not predict angular shifts, coating ripple, fluorescence or optical-density leakage.

The setup

A 532 nm beam passes a 500–550 nm and a 520–540 nm filter. Their nominal overlap is 520–540 nm; an upstream tap distinguishes source loss from rejection.

  1. Compare 532 nm input with 510 nm: only the first should survive both idealized stages.
  2. Set the second band to 560–580 nm and check the no-overlap boundary case.

Components in this setup

  • CW Laser
  • Beamsplitter
  • Filter
  • Photodetector

Arrangement and variants

Serial filters or double/triple monochromators with intermediate apertures.

Design constraints

Improved rejection costs throughput and can introduce ghosts or band-shape distortions.
