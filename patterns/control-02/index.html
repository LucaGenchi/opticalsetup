CONTROL-02 · Control architecture

Two-plane beam-pointing control

Distinguish and correct beam displacement and angle using separate observations.

Schematic exampleTwo-mirror correction from near and far sensors

Input beam — Beam with possible position and angle drift.

The example

Two separated steering mirrors are controlled using a near-field centroid and a far-field angle measurement so displacement and tilt can be distinguished.

  1. Compare a translated beam with a tilted beam at the two sensors.
  2. Explain why a single sensor cannot independently constrain both quantities.

Follow the arrangement

  1. Input beam (CW Laser) — Beam with possible position and angle drift.
  2. Steerer 1 (Mirror) — First independent angular actuator.
  3. Steerer 2 (Mirror) — Second actuator 300 mm downstream.
  4. Diagnostic split (Beamsplitter) — Sample the delivered beam.
  5. Experiment output — Main path after both actuators.
  6. Near-field sensor (Camera) — Image a beam plane to measure position.
  7. Far-field sensor (Camera) — Lens focal plane measures angular drift.
  8. Matrix controller — Use calibrated two-sensor/two-actuator coupling.

Design choices

Arrangement and variants

Two suitably separated or conjugate position measurements with steering actuators.

Key constraints

Observability, cross-coupling, sensor noise, and actuator bandwidth govern correction.
