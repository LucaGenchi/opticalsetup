Nested grazing-incidence imaging

Collect and image short-wavelength radiation using nested reflecting surface pairs.

Schematic exampleNested Wolter-I telescope shells

Distant X-ray field — Nearly parallel incoming rays occupy several shell annuli.

The example

Two illustrative nested shell pairs each use a paraboloid-like first graze and hyperboloid-like second graze to send distant X-rays to a common detector focus.

  1. Follow two reflections for each shell and distinguish nesting from multiple sequential full-aperture mirrors.
  2. Compare shell alignment errors with coating reflectivity; either can reduce useful imaging.

Follow the arrangement

  1. Distant X-ray field — Nearly parallel incoming rays occupy several shell annuli.
  2. Outer first reflection — Outer shell starts the two-reflection imaging path.
  3. Inner first reflection — Inner shell increases collecting area without using the same annulus.
  4. Outer second reflection — Second graze redirects the outer-shell beam to the common focus.
  5. Inner second reflection — Second graze matches the inner shell to the same image plane.
  6. Common telescope focus — Nested shells are registered to this image plane.
  7. X-ray focal detector (Photodetector) — Collects the image from all accepted shells.
