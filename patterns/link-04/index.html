Programmable interferometer mesh

Compose tunable couplers and phase shifts into a multimode optical transformation.

Diagram scope: Cell nodes summarize multiple phase shifters; no transfer matrix or calibration algorithm is executed. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

Six tunable 2×2 cells implement a four-port triangular network; two populated inputs can be routed to different output ports.

  1. Choose identity routing before attempting a mixing transform.
  2. Follow a calibration tap separately from the main output.

Follow the arrangement

  1. Inputs 1 / 2 — Two input amplitudes populate a four-mode network.
  2. Cells 12 / 23 — First adjacent-mode mixing layer.
  3. Cells 34 / 12 — Second layer couples an additional mode.
  4. Cells 23 / 12 — Final elimination and phase-setting layer.
  5. Outputs 1–4 — Four separately accessible channels.
  6. Calibration taps (Photodetector) — Monitor pilot signals when setting each cell.

Design choices

Arrangement and variants

Networks of Mach-Zehnder cells or equivalent tunable interferometers.

Key constraints

Loss accumulation, phase drift, calibration, and topology determine useful scale.
