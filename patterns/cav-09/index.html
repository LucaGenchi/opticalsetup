Coherent beam combining

Combine amplified channels while controlling their relative phases and modes.

The example

Split one 1064 nm master into two seeded amplifiers. A phase actuator in one arm stabilizes the selected combiner port using a low-power sample of the combined output.

  1. Trace the common seed and the return of the phase-error signal.
  2. Introduce a half-wave relative phase conceptually and identify the alternate combiner port.

Follow the arrangement

  1. Common master (CW Laser) — Shared seed supplies mutual coherence.
  2. Seed splitter (Beamsplitter) — Feeds two amplifier channels.
  3. Amplifier A — Reference channel must match polarization and spatial mode.
  4. Amplifier B + phase (Phase modulator) — A phase actuator corrects this channel.
  5. Coherent combiner (Beamsplitter) — Relative phase decides the useful output port.
  6. Combined output — Target port receives constructive interference.
  7. Phase-error pickoff (Photodetector) — Feedback senses a small output fraction.

Design choices

Arrangement and variants

Phase-controlled amplifier channels feeding a coherent combiner.

Key constraints

Phase errors, amplitude imbalance, and wavefront mismatch reduce useful combination.
