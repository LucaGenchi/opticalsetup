Follow the arrangement

  1. Excitation (CW Laser) — A fixed incident beam.
  2. Return separator (Dichroic mirror) — Directs the returning signal to detection.
  3. Shared galvo (Galvo mirror) — Outbound and return paths use the same pivot.
  4. Scanned specimen (Sample) — Objective images the scanned focal point.
  5. 50 µm fixed pinhole — Return image remains stationary after descan.
  6. Confocal detector (Photodetector) — Collect only the pinhole-transmitted return.

Design choices

Arrangement and variants

Collected light retraces the scanning optics before a detection branch.

Key constraints

Reciprocal path alignment is essential; non-descanned collection may suit scattered light better.
