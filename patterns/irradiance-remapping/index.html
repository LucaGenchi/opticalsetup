Patterns / Preparing and transforming beams

BEAM-05 · Pattern family · No setup available

Irradiance remapping

Redistribute an input intensity profile into a target profile.

No setup available

The source lacks a spatial Gaussian irradiance distribution and the registry has no solved two-surface Gaussian-to-top-hat energy-remapping prescription. Ordinary lenses or unsolved aspheres cannot demonstrate the required irradiance mapping.

Generic asphere icons do not supply a solved remapping prescription; no top-hat irradiance is simulated.

Arrangement and variants

Refractive, reflective, or diffractive beam shapers with a specified input distribution.

Design constraints

Performance depends on input profile, alignment, propagation distance, and wavelength.
