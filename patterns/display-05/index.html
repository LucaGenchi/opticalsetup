DISPLAY-05 · Optical layout

Retinal scanning projection

Build a displayed image by scanning modulated light through the eye pupil.

Schematic examplePupil-relayed raster retinal projector

Modulated RGB — Set intensity per raster pixel.

The example

An intensity-modulated RGB source feeds fast and slow scan axes; a relay conjugates the scanner pivot to the eye pupil.

  1. Locate the scanner-to-pupil conjugacy.
  2. Distinguish an image raster from a stationary focused beam.

Follow the arrangement

  1. Modulated RGB — Set intensity per raster pixel.
  2. Fast scan (Galvo mirror) — Example 15 kHz horizontal scan.
  3. Slow scan (Galvo mirror) — Example 60 Hz frame scan.
  4. Pupil relay (Conjugated thin lens pair) — Conjugate the scan pivot to the entrance pupil.
  5. Eye pupil (Human eye) — Accept angular raster without large pupil walk.
  6. Raster sequencer — Synchronize source intensity with both scan axes.
  7. Retinal image — Intended image formed by the eye optics.

Design choices

Arrangement and variants

Modulated source, scanning optics, pupil relay, and eye-facing delivery.

Key constraints

Pupil alignment, scan calibration, exposure limits, and eye motion constrain use.
