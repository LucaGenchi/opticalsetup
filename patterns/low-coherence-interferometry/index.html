FIELD-08 · Measurement architecture · Setup available

Low-coherence interferometry

Resolve optical path differences using broadband interference.

Open setup in canvas ↗Download setup

Model limits. This is the actual ray and spectrum collection front end of an OCT arrangement. The native receiver does not calculate a broadband spectral interferogram, k-linearization, depth reconstruction or axial resolution.

The setup

A native broadband source feeds a Michelson-like sample/reference front end. Two sample interfaces and a reference mirror return light to a native spectral receiver.

  1. Follow front-interface, back-interface and reference returns separately.
  2. Move the reference mirror and inspect the geometric optical-path change.

Components in this setup

  • Supercontinuum laser
  • Beamsplitter
  • Mirror
  • Spectrometer

Arrangement and variants

Reference and sample arms with delay-scanned or spectrally resolved readout.

Design constraints

Bandwidth, dispersion matching, sampling, and refractive index determine depth interpretation.
