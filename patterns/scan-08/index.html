SCAN-08 · Pattern family

Multipass propagation

Obtain a long interaction path in a compact volume.

Schematic exampleHerriott-cell multipass absorption

Probe input — Choose a near-infrared absorption wavelength.

The example

Two concave mirrors repeatedly pass a beam through a 200 mm gas cell before the selected exit aperture reaches a detector.

  1. Count physical traversals rather than multiplying by the number of mirror spots without checking the sequence.
  2. Distinguish a finite multipass orbit with an exit hole from a resonant cavity.

Follow the arrangement

  1. Probe input (CW Laser) — Choose a near-infrared absorption wavelength.
  2. Input/exit mirror (Concave mirror) — Entrance and exit holes select a finite spot sequence.
  3. 200 mm gas region (Gas cell) — Repeated traversals increase absorption path.
  4. Opposite mirror (Concave mirror) — Concave mirror supports a stable multipass orbit.
  5. Selected exit detector (Photodetector) — Only the selected exiting spot reaches detection.

Design choices

Arrangement and variants

Herriott or White cells; other geometrically closed sequences of reflections.

Key constraints

Spot separation, mirror apertures, accumulated loss, and injection/extraction govern pass count.
