Double-pass AOM

The example

A cat-eye return traverses an 80 MHz AOM twice; polarization separation extracts a nominal +160 MHz output while suppressing pointing sensitivity.

  1. Count two frequency shifts in the selected order.
  2. Follow the cat-eye return and identify why the extracted output uses the other PBS port.

Follow the arrangement

  1. Input laser (CW Laser) — Input linear polarization passes the PBS.
  2. Polarization separator (Polarizing BS) — Send and return occupy different polarization ports.
  3. 80 MHz AOM (AOM) — Selected diffraction order is traversed twice.
  4. Cat-eye lens (Thin convex lens) — Focus the selected order onto the end reflector.
  5. Quarter-wave / mirror (Mirror) — Double-pass polarization rotates the return by 90°.
  6. +160 MHz return — Extracted PBS return port.

Design choices

Arrangement and variants

AOM, return optics often in a cat-eye geometry, and polarization-based separation.

Key constraints

Diffraction efficiency, aperture, alignment, and RF bandwidth set the tuning range.
