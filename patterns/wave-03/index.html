WAVE-03 · Control architecture

Sensorless wavefront optimization

Optimize an optical quality metric instead of using a dedicated wavefront sensor.

Schematic exampleImage-metric optimization without a wavefront sensor

Pupil phase corrector — Applies trial aberration coefficients.

Diagram scope: No image metric, aberration basis search, convergence or improved resolution is calculated. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

A microscope applies five trial amplitudes for each of seven selected aberration modes on a pupil SLM. A fluorescence image-sharpness metric determines the next trial; final validation uses held-out specimen detail.

  1. Count the nominal 35 measurements and identify bleaching or specimen motion that can bias the search.
  2. Change the metric from brightness to sharpness conceptually and discuss different optima.

Follow the arrangement

  1. Pupil phase corrector (SLM) — Applies trial aberration coefficients.
  2. Microscope objective (Objective) — Transfers the corrected illumination and collection field.
  3. Stable fluorescent target (Sample) — Target changes must be slower than the optimization.
  4. Fluorescence camera (Camera) — Provides image data rather than wavefront slopes.
  5. Image-sharpness metric — Scores normalized image detail for each trial.
  6. Mode-amplitude search — Selects the next phase update from the metric history.
