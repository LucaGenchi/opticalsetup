Patterns / Stabilizing, calibrating, and diagnosing

CONTROL-05 · Control architecture · Setup available

Focus-lock channel

Use a dedicated optical signal to maintain a chosen focus condition.

Open setup in canvas ↗Download setup

Model limits. This native open-loop diagnostic uses an ideal mirror reference and a camera as the position sensor. It does not model a coverslip Fresnel reflection, microscope specimen focus, split-detector electronics, calibrated focus error or an automatic z-lock servo.

The setup

An off-axis 850 nm beam passes a PBS, quarter-wave plate and focusing lens to a reflective reference plane. A camera in the separated return port measures a centroid that changes when the reference plane moves axially.

  1. Move the reference mirror 10 mm along the lens axis and inspect the return camera centroid; the beam starts 10 mm off the lens axis.
  2. Set the quarter-wave axis to 0° to suppress the receive channel, separating lost return routing from a focus-related centroid change.

Components in this setup

  • CW Laser
  • Polarizing BS
  • λ/4 waveplate
  • Thin convex lens
  • Mirror
  • Camera

Arrangement and variants

Auxiliary probe or image metric with axial focus actuator.

Design constraints

The reference surface or metric must track the desired imaging plane.
