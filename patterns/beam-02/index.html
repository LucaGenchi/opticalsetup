Single-mode filtering

Project collected light onto a supported guided spatial mode.

The example

A 780 nm beam is coupled into a single-mode fiber with nominal 5 µm mode-field diameter, then recollimated for downstream use.

  1. Distinguish cleaning the output mode from preserving all input power.
  2. Check the fiber operating wavelength and match the input waist to the stated mode field.

Follow the arrangement

  1. 780 nm input (CW Laser) — Input may contain unwanted transverse modes.
  2. Input asphere (Thin convex lens) — Match waist and wavefront to the fiber mode.
  3. Single-mode fiber — Nominal MFD 5 µm; actual cutoff must suit 780 nm.
  4. Output collimator (Thin convex lens) — Sets output beam diameter.
  5. Rejected light (Beam dump) — Uncoupled power does not join the guided output.

Design choices

Arrangement and variants

Mode-matching optics feeding a single-mode fiber or waveguide.

Key constraints

Rejected modes become lost power; single-mode operation depends on wavelength and guide.
