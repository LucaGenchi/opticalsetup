Regenerative amplification

Trap a seed pulse for repeated amplification and then release it.

The example

An illustrative stretched 1030 nm seed enters through a polarizing coupler, circulates for a programmed 20 round trips and is switched out by a Pockels cell for later compression.

  1. Follow one round trip and locate the polarization gate rather than a permanent open output.
  2. Compare early extraction with more passes; gain saturation and nonlinear phase constrain useful storage.

Follow the arrangement

  1. Stretched seed pulse (Pulsed Laser) — Low peak intensity helps protect the gain medium.
  2. Injection / extraction PBS (Polarizing BS) — Polarization selects storage versus output.
  3. Timed Pockels cell (EOM) — Changes polarization to trap and release the pulse.
  4. Pumped gain crystal (Crystal) — Adds pulse energy each round trip.
  5. End mirror (Mirror) — Returns the stored pulse.
  6. Return mirror (Mirror) — Completes the round-trip storage path.
  7. Extracted pulse — Leaves after the chosen number of passes.

Design choices

Arrangement and variants

Gain cavity with timed injection and extraction, commonly using polarization switching.

Key constraints

Switch timing, gain saturation, dispersion, and accumulated nonlinear phase matter.
