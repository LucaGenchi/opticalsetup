BEAM-03 · Optical layout

Mode matching

Match beam size, waist location, and wavefront curvature to a receiving mode.

Schematic exampleTwo-lens cavity mode matching

1064 nm input — Nominal 1 mm beam radius.

Diagram scope: No Gaussian q propagation or cavity overlap is computed; the dimensions describe a design target, not a solved lens spacing. The editable diagram contains annotations and connection arrows; it does not run an optical simulation.

The example

A 50/100 mm adjustable lens pair targets a 100 µm waist at a cavity input mirror; matching size alone does not match curvature.

  1. Use the two movable lenses to control waist position and size independently.
  2. Compare both waist radius and wavefront curvature against the target eigenmode.

Follow the arrangement

  1. 1064 nm input (CW Laser) — Nominal 1 mm beam radius.
  2. 50 mm lens (Thin convex lens) — First degree of freedom changes convergence.
  3. 100 mm lens (Thin convex lens) — Position provides a second waist-control degree of freedom.
  4. 100 µm target waist — Desired waist belongs to the cavity eigenmode.
  5. Cavity input (Concave mirror) — Mode overlap determines usable injection.
  6. Target q parameter — Both spot size and wavefront curvature must agree.

Design choices

Arrangement and variants

One or more adjustable powered optics before a fiber, cavity, or gain region.

Key constraints

Alignment and phase-front overlap matter alongside geometric beam diameter.
