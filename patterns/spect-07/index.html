The example

Clean a 532 nm pump before the specimen, then place a long-pass edge filter in the return branch so Stokes-shifted Raman light can enter a slit spectrometer.

  1. Identify which filter operates before the sample and which after it.
  2. Move a hypothetical Raman line near the edge and check the tradeoff between pump rejection and low-shift access.

Follow the arrangement

  1. 532 nm pump (CW Laser) — Laser sidebands must be removed before interaction.
  2. Pump bandpass (Filter) — Passes the laser line while rejecting source background.
  3. Raman specimen (Sample) — Weak shifted light coexists with strong elastic scatter.
  4. Return edge filter (Filter) — Rejects the laser line while passing Stokes wavelengths.
  5. Spectrometer slit (Slit) — Receives the filtered Raman collection.
  6. Elastic-light rejection (Beam dump) — The bright pump channel must not reach the spectrometer.

Design choices

Arrangement and variants

Excitation cleanup filter followed by collection-side notch, edge, or band filters.

Key constraints

Filter edge placement, incidence angle, and residual fluorescence set usable sensitivity.
