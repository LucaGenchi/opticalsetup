FIELD-01 · Pattern family

Two-arm interferometry

Compare phase or path changes between distinct optical arms.

Schematic exampleMach–Zehnder phase measurement

532 nm laser — Shared coherent source.

The example

Two 50/50 beamsplitters form separate sample and reference arms at 532 nm, then recombine into two complementary camera ports.

  1. Compare separate sample and reference paths and both recombination outputs.
  2. A 266 nm optical-path change at 532 nm adds π phase; distinguish optical path from physical mirror travel.

Follow the arrangement

  1. 532 nm laser (CW Laser) — Shared coherent source.
  2. 50/50 input splitter (Beamsplitter) — Creates two arms.
  3. Sample arm (Phase object) — A phase object changes optical path.
  4. Reference arm (Mechanical delay line) — Adjustable optical delay.
  5. Recombiner (Beamsplitter) — Spatial mode and polarization must overlap.
  6. Camera port A (Camera) — One complementary output.
  7. Camera port B (Camera) — Complementary output checks total power.

Design choices

Arrangement and variants

Michelson or Mach-Zehnder split, propagate, and recombine arrangements.

Key constraints

Coherence, mode overlap, differential drift, and polarization set interference visibility.
