QUANT-02 · Pattern family

Indistinguishable-path entanglement generation

Superpose indistinguishable generation alternatives to prepare entangled outputs.

Schematic examplePolarization Sagnac pair source

Diagonal pump — Equal coherent pump amplitudes for both loop directions.

The example

A diagonally polarized 405 nm pump drives clockwise and counterclockwise pair-generation paths in one loop; two 810 nm analysis arms test correlations.

  1. Identify the two generation alternatives that must remain indistinguishable.
  2. Compare polarization analysis with classical intensity tracing.

Follow the arrangement

  1. Diagonal pump (CW Laser) — Equal coherent pump amplitudes for both loop directions.
  2. Loop PBS (Polarizing BS) — Launch orthogonal polarization components in opposite directions.
  3. Loop crystal (Crystal) — Common generation region for indistinguishable alternatives.
  4. Loop fold (Mirror) — Close the counterpropagating paths.
  5. Analyzer A (Polarizer) — Example analysis angle 0°.
  6. Analyzer B (Polarizer) — Example analysis angle 45°.
  7. Coincidence unit — Record paired outcomes from both analyzer ports.

Design choices

Arrangement and variants

Polarization-Sagnac, crossed-crystal, or coherently pumped multiple-source arrangements.

Key constraints

Unwanted distinguishability, phase drift, and collection mismatch reduce state quality.
