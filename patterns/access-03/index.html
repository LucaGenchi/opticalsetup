Proximal scanning through an image guide

The example

A 488 nm spot scans across the proximal bundle face. The addressed distal core illuminates one tissue location; the same core carries the fluorescence back to a conjugate pinhole detector.

  1. Identify where scanning occurs and which core defines the illumination/collection correspondence.
  2. Compare scan step size with core pitch; oversampling cannot create information between cores.

Follow the arrangement

  1. 488 nm excitation (CW Laser) — Feeds a proximally located scan system.
  2. Proximal scanner (Galvo mirror) — Selects bundle cores without moving distal hardware.
  3. Return pickoff (Dichroic mirror) — Separates return fluorescence from excitation.
  4. Coherent bundle — Maintains correspondence between addressed cores and distal positions.
  5. Distal tissue (Sample) — One selected core illuminates its mapped region.
  6. Conjugate pinhole (Slit) — Selects the descanned proximal return.
  7. Confocal detector (Photomultiplier (PMT)) — Raster timing assigns signal to each addressed location.

Design choices

Arrangement and variants

Proximal focused scan across an image bundle with distal delivery optics.

Key constraints

Core sampling, coupling, and return-path behaviour constrain field and resolution.
