Common-path interferometry

Share much of the propagation path between signal and reference.

The example

A focused field crosses a pinhole reference mask: a small spatially filtered component supplies the reference and the remaining field carries specimen phase.

  1. Identify where the reference is generated from the measured field.
  2. Compare common downstream disturbances with disturbances before the pinhole reference formation.

Follow the arrangement

  1. Phase specimen (Phase object) — Specimen modifies the incident wavefront.
  2. Fourier lens (Thin convex lens) — Forms a focus at the reference mask.
  3. Reference pinhole mask — Small hole generates a smooth reference wave.
  4. Interference camera (Camera) — Reference and object fields propagate together.
  5. Filtered reference — Co-propagating reference is derived from the same field.

Design choices

Arrangement and variants

Spatial, polarization, or temporal encoding along substantially shared optics.

Key constraints

Shared paths reduce selected differential disturbances, not all noise or calibration errors.
