# Integrated scene rework

Selected architecture set: Fischer, Gittard, Somers, Ouyang and Gu. The Basic
scene is the common visual reference in `../setups/basic-2pp.json`. Selection
is based on the eleven source/native reports; browser acceptance is still an
open gate while the shared browser connection is unavailable.

Use one 4:3 to 3:2 landscape frame, a short title, a single concise mechanism /
limits note, source at upper left, real compact folding, objective/sample
treatment toward lower right. Basic uses a 720 × 540 frame, 18-unit element
labels and body text, a 28.8-unit title, muted slate notes, wavelength rays,
and an optional actual-arrival detail at the sample. Match perceived sizes
when reported distances need a larger frame. Target at least 11–12 px text
when the frame fits a roughly 500 px canvas. Move long prose to the evidence
page. Preserve actual optical path distances when folding; never geometrically
scale a reported prescription without explicit disclosure.

All paper notes must visibly identify `Design choice = free interpretation;
not specified in the paper.` Shorter on-canvas wording may point to the full
key in the companion note. Reported assumptions and measured values are
distinct. Avoid tiny source-spec dumps and untraced auxiliary replicas.

Use the unified programmable mask and actual-arrival model. Phase colors do
not solve a hologram; physical orders are configured separately. A 2D frame
may have a sampled column, clearly shown. No conveyor motion, no fictitious
sharp centroid, no calculated voxel or chemistry claim. Default light must
show the distinct mechanism immediately. Terminate sample transmission when
it only produces a distracting unobserved fan.

Validate full beam support, not only reference markers. Check each optical
channel at the sample, aperture losses, and the actual objective BFP. The
objective stop is now at the BFP, including high-NA and long-WD cases. A
fixed-window arrival inset displays actual samples in micrometers and can
make small movement visible without exaggerating geometry.

Each author owns only their integrated scene JSON, evidence note, scene test
and native SVG preview. Shared issues return to the coordinator. Record three
useful controls, full-beam and relevant relay tests, default and boundary
results, and save/reload. No original branch edits. No browser call until the
coordinator releases the browser slot. Native SVG inspection is useful for
layout but is never described as browser evidence.
